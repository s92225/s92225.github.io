# 夾夾島 · Candy Jelly 可玩網頁 MVP 0.6.2

正式網站：https://s92225.github.io/

GitHub Actions 會喺每次更新後自動測試、建置同發佈到 GitHub Pages。網站已加入私隱政策及 Google AdSense publisher `ca-pub-8769011123659282` 所需嘅擁有權驗證檔案。

手機直向 3D 夾爪關卡遊戲。最新產品方向是純數碼關卡制；0.3 以前的「遊戲＋獨立實物商店」已被取代。玩家流程不再有實物商品、購物袋、結帳、訂單、寄送或實物兌換。

## 開啟與測試

- 關卡地圖：http://127.0.0.1:4173/#levels
- 第一關：http://127.0.0.1:4173/#play/1
- 本機物理測試頁：http://127.0.0.1:4173/#lab
- 開發預覽：http://127.0.0.1:5173/

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

兩個伺服器只綁定 127.0.0.1，沒有公開發布。`#lab` 只供本機物理調校，不增加玩家關卡、收藏或金幣；它不是正式管理後台。

## v0.6 已實作

0.6.1 將完成關卡結算移到機台以外的全畫面彈出層，鎖定背景捲動並在不同手機高度都保留「下一關」按鈕。32 件圖鑑寶物現時全部使用 Candy Jelly 專屬分層 SVG 插畫，不再以字型、Emoji 或通用黑色符號代替；自動測試會檢查每件寶物都有獨立畫稿及足夠矢量細節。

0.6.0 將旅程擴展至 30 關。第 9–30 關加入咖啡杯、遙控器、鎖匙、眼鏡、筆記簿、原子筆、銀包、梳、耳機盒、縮骨遮、番梘、牙膏、相機、手錶、波鞋、太陽帽、飯盒、充電器、電筒、玩具車、湯匙及膠紙座；每件都有獨立 model ID、多組件 3D 外形、圖鑑圖案及物理規格，並通過爪距及置中完整夾取測試。

三星改成三個獨立條件：在目標數量內完成、每一夾都在十秒內主動落夾、全關不使用錦囊。條件會逐粒保存，重玩可補回未達成的星。收藏頁改為 32 格圖鑑，每種寶物只記錄「已登錄／未發現」，舊存檔的重複數量會遷移成一次登錄。錦囊卡的名稱置頂置中，庫存圖示在中間，底部同時提供金幣及廣告補充按鈕。

0.5.3 玩家頁完全移除難度圖示，只保留剩餘夾數。第 5 關紙巾降低少量重量、提高表面抓握並重新分隔擺位；兩個爪墊真實碰到紙巾後會提供有限夾持力，兩包紙巾都可連續送入出口。黏力錦囊仍更強，只需一點接觸即會黏住。三個錦囊在圖示下加入「加夾／黏力／重排」短名。機內目標及 `+5` 標記改成圓角糖果牌，加入漸變、端點糖珠及星光。夾中任務目標後，會放大旋轉該件實際 3D 模型，配合星星爆發、彩色光圈及煙花動畫；完成關卡會停留較長時間再自動進入下一關。

## 物理與公平性

使用 Three.js 0.180.0 與 cannon-es 0.20.0，固定 120 Hz。玩家關卡固定使用純物理：一般夾取以有限接觸壓力及摩擦抓取動態剛體，第 5 關輕質紙巾在兩爪墊已經握實後加上有限夾持約束，不會從遠處吸附物件，也沒有隱藏成功率。接觸不足會傾斜或滑落，物件實際進入前左出口才計分。

黏力夾是玩家主動換取、畫面明示的一次性輔助：下一夾在至少一個爪墊真實接觸物件後加上暫時黏附，移到出口上方便解除。它不改成功率，亦不會把未接觸的物件吸近或直接計成成功。

`#lab` 保留容易／標準／挑戰及明示機率示範，用來調校抓力；這些控制不出現在玩家頁，也不會改玩家關卡規則。

這仍是簡化剛體原型：手指只有尖端接觸、物件不會軟體變形，參數未按實機標定。進行中的單次夾取不跨重新整理保存；已完成關卡、星數、收藏、示範金幣及設定會保存。
